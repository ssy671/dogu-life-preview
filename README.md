# 도구생활

https://ssy671.github.io/dogu-life-preview/

디지털 정리·업무 습관·도구 활용을 다루는 한국어 블로그입니다. 공개 글과 앞으로 발행할 검토 원고를 포함합니다.

## 운영

기존 90일 운영 계획은 [OPERATING_PLAN.md](OPERATING_PLAN.md)에 별도로 보관합니다.

- 한국 시간 오전 9시: 대기 원고를 하루 3편 발행합니다. 오늘 이미 발행했으면 반복 실행해도 추가하지 않습니다.
- 매시간 7분: 외부 조회수 카운터의 읽기 API를 조회하고 인기순 집계를 갱신합니다.
- GitHub 예약 실행은 지연될 수 있으며 다음 실행에서 그날의 세 편을 발행합니다. 며칠 중단되어도 하루에 밀린 글 전체를 공개하지 않습니다.
- 대기 원고의 남은 분량은 실행 결과와 `content/queue.json`에서 확인합니다. 소진 전에 `content/queue.json`에 새로운 검토 원고를 보충해야 합니다. API 키 없이 동작하며 글을 무한 자동 생성하지 않습니다. 큐가 9편 미만이면 실행 결과에 경고가 남습니다.

## 화면

- 글별 도해와 본문 중간에 배치한 주제별 생성 일러스트 (반응형 WebP, 대체텍스트·설명 포함)
- 한국 날짜 기준 오늘 글과 NEW 표시, 오늘 글이 없으면 최근 글
- 최신순·인기순, 분류·검색·오늘 글 교차 필터, URL 공유와 뒤로가기 복원
- 제목·요약·본문 전체 검색: 일치한 본문 문맥과 검색어 강조 표시
- 글의 자동 목차와 소제목 옆 `#` 구간 링크 (JavaScript 없이 동작)
- 하단 `RSS 구독` 링크와 `feed.xml`: 발행된 글만 최신순으로 제공
- 댓글 기능은 없고 인기도는 조회수를 기준으로 계산합니다.

## 포인터 물결 효과

마우스로 빈 페이지 여백이나 첫 화면 일러스트 배경을 지나면 잔잔한 동심원이 퍼집니다. 본문·링크·광고 위에는 그리지 않으며, 터치 기기와 움직임 줄이기 설정에서는 꺼집니다. 숨겨진 탭과 페이지 이동에서는 즉시 정리됩니다. 최대 8개, 110ms 간격의 짧은 장식 애니메이션만 사용하며 추가 외부 요청이나 추적은 없습니다.

## 조회수

`hits.sh`의 가입 없는 공개 카운터를 사용합니다. 독자가 글을 열면 배지 이미지를 불러와 조회가 집계됩니다. 실제 사람 수가 아닌 이미지 요청 수이므로 재방문·새로고침·봇·임의 호출을 포함할 수 있습니다. 숫자는 매시간 공유 스냅샷에 반영됩니다. 외부 서비스 장애 시 기존 값을 보존합니다. 최초 집계는 0이며 과거 조회수를 추정해 만들지 않습니다.

서비스 공개 API: `https://hits.sh/api/urns/ssy671.github.io/dogu-life-preview/post/{slug}` (읽기)

배지: `https://hits.sh/ssy671.github.io/dogu-life-preview/post/{slug}.svg` (집계)

추적 거부가 켜져 있거나 `?test=1`인 경우 카운터 이미지를 불러오지 않습니다. 개인정보 처리 안내에 외부 요청을 명시했습니다.

## 소스

`content/posts.json`: 발행 글의 전체 본문과 발행 시각.

`content/queue.json`: 앞으로 발행할 검토 글. 첫 3편을 순서대로 소비합니다.

`content/state.json`: 마지막 발행 날짜와 한국 시간 설정.

`content/views.json`: 마지막으로 읽은 공개 조회수.

`content/illustrations.json`: 발행 글·예약 글의 이미지, 대체텍스트, 설명과 본문 삽입 위치. 예약 글도 발행할 때 지정한 이미지를 사용하며 별도 이미지 API 호출은 하지 않습니다.

`docs/static/illustrations`: 웹용으로 압축한 생성 일러스트.

`docs`: GitHub Pages 게시 폴더. `scripts/build.py`가 글과 그림을 생성합니다.

`Publish daily articles and refresh views`는 수정본을 저장하고 같은 작업에서 Pages artifact를 직접 배포합니다. GitHub 토큰이 만든 커밋이 다른 workflow를 시작하지 않는 경우에도 배포됩니다. 기존 Pages의 main /docs 설정은 유지합니다. 다른 변경이 동시에 생겨 push가 거부되면 강제로 덮어쓰지 않고 다음 실행에서 최신 소스로 다시 시도합니다.

## 검증

```bash
python -m unittest discover -s tests -v
python scripts/build.py
```

CI는 실제 Chromium으로 PC·모바일 정렬, 필터, 기록 복원, 본문 그림과 가로 넘침을 검사하고 모든 공개 글과 도해 URL의 HTTP 응답을 확인합니다. 브라우저 검사에서는 외부 조회수를 올리지 않습니다.
