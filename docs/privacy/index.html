사이트 이용과 조회수 #

이 사이트에는 독자 회원가입과 댓글 기능이 없습니다. 글의 인기도를 보여 주기 위해 hits.sh의 공개 조회수 카운터를 사용합니다. 글을 열면 해당 서비스에 이미지 요청이 전송되며 글의 경로와 접속 IP, 브라우저 요청 정보가 전달될 수 있습니다. 카운터는 고유 독자 수가 아닌 이미지 요청 수를 바탕으로 하며 새로고침이나 자동 요청이 포함될 수 있습니다.

집계와 외부 서비스 #

글별 누적 조회수는 공개된 값이며 매시간 사이트에 반영합니다. 외부 서비스가 응답하지 않으면 마지막으로 확인한 집계를 유지합니다. 브라우저의 추적 방지 설정에 따라 집계되지 않을 수 있습니다. 사이트를 제공하는 Cloudflare와 글꼴을 제공하는 Google Fonts에도 IP 주소와 브라우저 요청 정보가 전달될 수 있습니다.

이메일 문의 #

문의하실 때 보내주신 이메일 주소와 내용은 답변과 문의 처리에 사용합니다. 콘텐츠 오류와 개인정보 관련 문의는 문의 페이지를 이용해 주세요. 외부 서비스의 상세 처리 정책과 선택 방법은 각 제공자의 안내를 확인할 수 있습니다.
