표정으로 충전을 알려주는 UGREEN Uno 케이블

USB-C 기기의 충전과 기본 데이터 전송에 쓰는 LED 표정 케이블입니다. 비교한 판매 옵션은 1m U-35501입니다.

확인일 기준 표시가격 · 1m U-35501 기본 판매가 18,600원 + 배송비 2,500원. 쿠폰 적용가는 대상·조건에 따라 달라집니다. 최종 결제금액과 재고는 판매처에서 확인해 주세요.

직접 사용하지 않았습니다. 아래 내용은 확인한 자료를 바탕으로 정리했습니다.

자료에서 확인한 특징

  • 제조사 자료에 LED 스마일 표시와 최대 PD 100W 충전 지원이 명시되어 있습니다.
  • 알루미늄 외장과 나일론 편조 소재를 사용하며, 데이터 전송 규격은 최대 480Mbps입니다.

한계와 확인할 점

  • 100W는 케이블의 지원 상한입니다. 실제 충전 속도는 충전기와 기기 지원 조건에 따라 달라집니다.
  • 480Mbps 규격이므로 고속 외장 SSD 용도에는 제한적입니다. 영상 출력 지원은 확인하지 못했습니다.
  • 국내 판매자의 목록에 구매 1건·상품평 1개가 표시되어 있습니다. 판매처 표시 수치이며 실제 구매 내역은 독립적으로 검증하지 못했습니다. 주소별 배송 가능 여부도 미확인입니다.

표정이 있는 UGREEN Uno 6-in-1 USB-C 허브

노트북의 USB-C 포트에 연결하는 로봇 표정 멀티허브입니다. 조사한 판매 구성은 U-35998 단품이며, 데이터용 USB-C 2개·USB-A 2개, HDMI와 PD 전원 입력을 제공합니다.

확인일 기준 표시가격 · U-35998 단품 기본 판매가 41,300원(KRW), 기본 배송비 무료. 제주 추가 3,000원·도서산간 추가 5,000원 안내. 39,240원은 5% 쿠폰 적용 조건부 가격입니다. 주소별 배송 가능 여부·재고·최종 결제금액은 미확인입니다.

직접 사용하지 않았습니다. 아래 내용은 확인한 자료를 바탕으로 정리했습니다.

자료에서 확인한 특징

  • 제조사 자료상 상태 이모지 4종과 최대 10Gbps USB 3.2 Gen 2 데이터 포트 4개를 제공합니다.
  • HDMI 최대 4K 60Hz 출력과 PD 전원 연결을 한 허브로 처리할 수 있습니다. Windows·macOS·Linux에서 플러그 앤 플레이를 지원한다고 안내합니다.

한계와 확인할 점

  • HDMI를 사용하려면 연결 기기의 USB-C 포트가 영상 출력을 지원해야 합니다. 10Gbps라고 표시된 USB-C 포트는 데이터 전용이며 영상 출력용이 아닙니다.
  • PD 입력은 최대 100W지만 노트북으로 전달하는 충전 출력은 최대 85W이고 15W는 허브용으로 예약됩니다. PD 충전에는 별도 호환 충전기와 케이블이 필요하며, 해당 판매 구성의 동봉 여부는 미확인입니다.
  • 제조사 한국어 페이지는 애플 정품 100W 충전기와 호환되지 않는다고 안내합니다. 개별 충전기·노트북 조합의 동작, 발열과 실제 전송 속도는 직접 시험하지 않았습니다.
  • G마켓 해당 상품의 검색 목록에는 구매 1건, 상세 페이지에는 상품평 0개가 표시됩니다. 판매처 표시일 뿐 실제 구매 내역은 독립 검증하지 못했습니다. 재고·주소별 배송·국내 보증 조건은 미확인입니다.

고개를 드는 UGREEN Uno W709 무선충전기

로봇 표정과 각도 조절 거치대를 갖춘 Qi2 무선충전기입니다. 조사한 국내 판매 옵션은 W709이며, 휴대폰 최대 15W·이어폰 최대 5W 무선충전과 별도 5W USB-C 출력을 제공합니다.

확인일 기준 표시가격 · 2026-11-16 확인: 옥션 상품 01 W709 표시 할인가 59,900원(KRW, 기준가 60,000원에서 판매자 100원 할인). 15,000원 이상 기본 배송비 무료이며 제주 추가 2,500원·기타 도서 추가 4,000원 안내. 별도 전원 어댑터 비용은 포함하지 않았습니다. 재고·주소별 배송 가능 여부·최종 결제금액은 미확인입니다.

직접 사용하지 않았습니다. 아래 내용은 확인한 자료를 바탕으로 정리했습니다.

자료에서 확인한 특징

  • 제조사 자료상 Qi2 인증 휴대폰 충전부와 이어폰 충전부를 함께 사용하며, 표정 화면으로 충전 상태를 보여 줍니다.
  • 상단 충전부는 최대 70도까지 각도를 조절할 수 있어 책상 위 휴대폰 거치대로도 사용할 수 있습니다.

한계와 확인할 점

  • USB-C 외부 전원이 필요합니다. 제조사 구성에는 약 1m USB-C 케이블이 포함되고 전원 어댑터는 제외됩니다. 국내 판매 구성의 동봉품과 권장 어댑터 출력·규격은 구매 전 확인이 필요합니다.
  • 제조사는 아이폰과 자석 호환 케이스 또는 케이스 없는 사용을 권장합니다. 이어폰은 무선충전 지원 케이스가 필요하며, 개별 휴대폰·케이스 조합의 호환성과 실제 충전 속도·발열은 직접 시험하지 않았습니다.
  • 판매명에 표시된 25W는 휴대폰 단독 무선충전 속도가 아닙니다. 휴대폰 15W, 이어폰 5W, USB-C 출력 5W로 구분되며, 시계 충전에는 별도 충전 모듈이 필요합니다.
  • 구매 수량·해당 옵션의 상품평 수·재고·주소별 배송·국내 보증은 미확인입니다. 공식 제품 이미지이며 직접 촬영하거나 사용한 사진이 아닙니다.
