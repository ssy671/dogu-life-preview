참고 자료는 주소와 함께 근거를 남겨야 다시 쓸 수 있습니다

자료의 제목, 발행 주체, 확인 시점과 인용 맥락을 함께 기록해 출처를 다시 검증하기 쉽게 만듭니다.

  3. 글을 내보내기 전에 다시 열어보세요

좋은 문장이나 통계를 발견하면 링크만 저장하기 쉽습니다. 시간이 지나 다시 열어보면 왜 필요한 자료였는지 기억나지 않거나 내용이 바뀌어 있을 수 있습니다. 출처 기록은 북마크를 많이 모으는 것과 다릅니다. 나중에 같은 주장에 근거가 되는지 확인할 수 있도록 자료의 맥락을 남기는 작업입니다.

주장과 출처를 한 쌍으로 적으세요 #

먼저 무엇을 뒷받침하려고 자료를 찾았는지 한 문장으로 씁니다. 이어 자료 제목, 발행 주체, 게시 또는 수정 날짜, 확인한 날짜, 주소를 기록합니다. 날짜가 보이지 않으면 임의로 채우지 말고 확인되지 않았다고 표시하세요. 검색 결과의 짧은 설명만 읽고 근거로 삼지 말고 원문에서 해당 내용을 확인해야 합니다.

예를 들어 업무 도구의 기능을 설명하려면 개인의 후기보다 해당 서비스의 공식 안내에서 조건을 확인하는 편이 적절할 수 있습니다. 반대로 실제 사용자의 불편을 소개하는 글이라면 후기의 맥락이 도움이 됩니다. 자료의 성격과 설명하려는 주장이 맞는지 살펴보세요. 공식 자료라는 이유만으로 모든 비교나 평가까지 증명되는 것은 아닙니다.

인용과 해석을 구분해서 남기세요 #

자료에서 그대로 가져온 문장은 인용 표시를 하고, 자신이 정리한 해석은 따로 적습니다. 긴 문단을 복사하기보다 필요한 근거의 위치와 짧은 요약을 남기면 출처를 다시 확인하기 쉽습니다. 숫자를 기록할 때는 단위, 대상, 조사 기간, 적용 조건도 함께 적어야 합니다. 조건을 빼면 원래 자료와 다른 뜻이 될 수 있습니다.

보고서라면 해당 쪽이나 절의 이름을 적고, 웹 문서라면 관련 소제목을 기록합니다. 자료를 내려받아 보관할 때는 배포 조건과 저작권을 확인하세요. 내부 문서를 근거로 활용한다면 저장 위치뿐 아니라 누가 열람할 수 있는지도 고려해야 합니다. 공개 글의 출처란에 비공개 자료 주소를 넣어도 독자가 검증할 수는 없습니다.

글을 내보내기 전에 다시 열어보세요 #

초안에 넣었던 출처는 발행 직전에 다시 확인합니다. 링크가 열리는지, 내용이 바뀌었는지, 현재 문장이 근거의 범위를 넘어서지 않는지 살펴보세요. 여러 글이 같은 보고서를 인용한다면 중간 글을 계속 따라가기보다 가능한 범위에서 원자료를 확인하는 편이 정확합니다.

오늘 수집한 자료 하나부터 주장, 근거 위치, 확인 날짜를 붙여보세요. 모든 자료를 복잡한 서지 형식으로 정리할 필요는 없습니다. 다음 사람이 원문을 찾아 같은 조건으로 확인할 수 있다면 충분히 쓸모 있는 출처 기록입니다.

조회수는 외부 서비스로 집계하며 새로고침·봇 요청이 포함될 수 있습니다.
