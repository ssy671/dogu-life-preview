새 앱으로 옮기기 전, 내보낸 자료를 다시 열어 보세요

작은 표본을 내보내고 가져오며 본문, 첨부 파일과 연결 관계가 얼마나 보존되는지 확인합니다.

새 앱의 화면이 마음에 들어도 기존 자료를 옮기는 과정에서 첨부 파일이나 문서 사이의 연결이 사라질 수 있습니다. 내보내기 기능이 있다는 사실만으로 이전이 끝나는 것은 아닙니다. 실제로 사용하는 자료 몇 개를 골라 내보내고 새 도구에서 열어 본 뒤 전체 이전 여부를 결정하세요.

쉬운 자료와 복잡한 자료를 함께 고르세요 #

짧은 텍스트뿐 아니라 표, 이미지, 첨부 파일과 내부 링크가 있는 자료를 표본에 포함합니다. 무엇이 반드시 유지되어야 하는지 먼저 정하세요. 내용 보존과 모양 보존은 다른 요구입니다. 검색 가능한 텍스트가 필요한데 화면을 이미지로만 저장하는 방식은 목적에 맞지 않을 수 있습니다.

파일이 생겼는지보다 내용을 확인하세요 #

내보낸 파일을 원래 앱 밖에서 열어 보고, 새 앱으로 가져온 뒤 제목과 본문, 첨부 자료를 대조합니다. 날짜, 태그와 문서 간 링크처럼 부가 정보도 필요하다면 확인 항목에 넣습니다. 계정 권한과 공유 범위는 자료와 함께 그대로 옮겨지지 않을 수 있으므로 새 환경에서 별도로 점검하세요.

되돌아갈 수 있을 때 전체 이전을 결정하세요 #

표본에서 빠지는 정보가 발견되면 보완 방법과 수작업 시간을 계산합니다. 원래 계정이나 자료를 먼저 삭제하지 말고 새 환경에서 필요한 작업을 완료해 본 뒤 정리 여부를 결정하세요. 이동 기간에는 어느 쪽을 원본으로 수정할지 정해 두어 두 곳의 내용이 따로 바뀌는 것을 막습니다. 이전 후 유지할 기능과 포기할 기능이 명확해야 새 도구의 장점을 실제 업무와 비교할 수 있습니다.

조회수는 외부 서비스로 집계하며 새로고침·봇 요청이 포함될 수 있습니다.

  • 수정본 두 개를 합칠 때는 파일 날짜보다 변경 내용을 보세요
  • CSV를 가져오기 전, 앞자리 0과 날짜부터 비교하세요
