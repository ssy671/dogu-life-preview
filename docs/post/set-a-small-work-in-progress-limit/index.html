시작한 일이 너무 많다면, 새로 시작할 조건을 정해 보세요

진행 중·대기·완료를 구분하고 새 작업을 시작하기 전에 끝내거나 멈출 일을 정하는 방법입니다.

  2. 끝낼 작은 단위를 정하세요
  3. 제한은 시험한 뒤 조정하세요

할 일 목록은 길지 않은데 여러 문서와 창을 오가느라 하루가 끝날 때가 있습니다. 시작한 작업 수가 많으면 각 작업의 맥락을 다시 떠올리는 부담도 커집니다. 무조건 동시에 한 가지 일만 하겠다고 정하기보다, 실제로 진행 중인 일을 살펴보고 새 작업을 시작할 조건을 정해 보세요.

진행과 대기를 구분하세요 #

열어 둔 문서 수가 곧 진행 중인 업무 수는 아닙니다. 지금 직접 행동할 수 있는 작업, 응답을 기다리는 작업과 참고용 자료를 나눕니다. 각 작업이 다음 단계로 넘어가려면 무엇이 필요한지도 한 줄씩 적으세요. 대기 상태의 작업을 계속 붙잡고 있는 시간을 줄일 수 있습니다.

끝낼 작은 단위를 정하세요 #

‘보고서 완성’이 너무 크다면 ‘표 하나를 검증하고 출처를 기록’처럼 확인 가능한 단위를 정합니다. 새 요청이 들어오면 현재 단위를 마칠지, 중단하고 우선순위를 바꿀지 판단하세요. 중단한다면 마지막으로 확인한 위치와 다음 행동을 적습니다. 급한 일을 받으면서 기존 약속이 그대로 유지된다고 가정하지 않는 것이 중요합니다.

제한은 시험한 뒤 조정하세요 #

자신의 역할에 맞춰 동시에 진행할 작업 수를 작게 정하고 며칠간 관찰합니다. 대기 시간이 많은 업무와 긴 집중이 필요한 업무는 조건이 다를 수 있습니다. 완료한 양뿐 아니라 긴급 요청을 놓쳤는지, 대기가 길어졌는지도 함께 보세요. 숫자를 지키는 것 자체보다 작업 전환과 미완료 항목이 줄어드는지가 판단 기준입니다.

조회수는 외부 서비스로 집계하며 새로고침·봇 요청이 포함될 수 있습니다.

함께 읽으면 좋은 글

  • 작은 자동화를 넘겨줄 때는 실행 방법보다 멈추는 방법부터 적으세요
  • 답변을 기다리는 일은 내 할 일과 다른 목록에 두세요
  • 결정이 자꾸 되풀이된다면, 결론 옆에 바꿀 조건을 적어 보세요
