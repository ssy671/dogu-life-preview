가입한 계정 목록을 만들 때, 암호 없이도 관리할 수 있습니다

계정 목록에는 서비스·용도·접근 수단만 정리하고, 비밀번호와 복구 코드는 별도 보안 수단으로 관리하세요.

이 글의 목차

  1. 서비스와 사용 목적부터 적으세요
  2. 비밀 정보와 위치 안내를 분리하세요
  3. 정리할 때는 연결 관계도 확인하세요

오랫동안 쓰지 않은 서비스에서 안내 메일이 오면 가입 여부나 사용 목적이 기억나지 않을 때가 있습니다. 계정 목록은 모든 로그인 정보를 한곳에 적는 문서가 아니라, 어떤 서비스를 왜 이용하는지 확인하는 지도에 가깝습니다. 목록만으로 로그인할 수 없도록 만들면서도 유지와 종료를 판단할 단서는 남길 수 있습니다. 시작은 자주 사용하는 계정 몇 개만 정리하는 것으로 충분합니다.

서비스와 사용 목적부터 적으세요 #

각 항목에 서비스 이름, 사용 목적, 개인용인지 업무용인지, 가입한 계정을 구분할 단서를 적습니다. 예를 들어 같은 협업 도구를 개인 이메일과 회사 이메일로 이용한다면 어느 공간이 어느 업무에 연결되는지 표시하세요. 이메일 주소 전체가 불필요한 환경에서는 구분 가능한 일부 정보만 적어도 됩니다. 결제 중인지, 공동 관리자가 있는지도 종료 여부를 판단할 때 도움이 됩니다. 정확히 기억나지 않는 가입 일자나 요금은 추측해 채우지 말고 ‘확인 필요’로 남깁니다. 목록 자체에도 개인 정보가 모일 수 있으므로 공개 문서로 만들지 않습니다.

비밀 정보와 위치 안내를 분리하세요 #

비밀번호, 일회용 인증 코드, 복구 코드, 비밀 질문의 답을 계정 목록에 직접 적지 않습니다. 해당 정보는 적절한 비밀번호 관리 도구나 조직에서 승인한 방식으로 보관하고 목록에는 관리 수단만 기록하세요. 예를 들어 ‘업무용 암호 관리자에서 관리’처럼 쓰면 됩니다. 복구 이메일이나 인증 수단도 남이 그대로 악용할 수 있는 상세 내용을 펼쳐 두기보다 사용할 수 있는 상태인지 확인하는 데 초점을 둡니다. 공용 계정은 개인 휴대전화 하나에만 복구가 의존하지 않는지 살펴보고, 변경은 서비스와 조직의 절차에 맞춰 진행합니다.

정리할 때는 연결 관계도 확인하세요 #

사용하지 않는 계정을 발견했다고 바로 탈퇴하기보다 저장 자료, 구독, 다른 서비스의 로그인 연결을 먼저 확인합니다. 하나의 계정으로 다른 서비스에 로그인하고 있다면 삭제 후 접근이 끊길 수 있습니다. 필요한 자료를 확보하고 담당자를 확인한 다음 종료 여부를 정하세요. 개인 계정에 업무 자료가 섞인 경우에는 임의로 외부에 옮기지 말고 정해진 이관 방법을 따릅니다. 목록에는 마지막으로 확인한 날짜와 유지 이유를 남기면 다음 점검이 쉬워집니다. 계정을 많이 줄이는 것보다 필요한 계정의 책임과 복구 수단이 분명한 상태를 목표로 삼으세요.

조회수는 외부 서비스로 집계하며 새로고침·봇 요청이 포함될 수 있습니다.

함께 읽으면 좋은 글

  • 프로젝트가 끝난 뒤, 자료를 넘겨받을 사람을 위한 정리
  • 종이 영수증을 디지털로 남길 때, 사진보다 중요한 정보
  • 임시 메모가 쌓일 때, 보관보다 먼저 다음 행동을 정하세요
