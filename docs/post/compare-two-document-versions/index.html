같은 문서를 두 사람이 따로 고치면 가장 최근 날짜의 파일을 고르는 것만으로는 다른 사람의 수정이 보존되지 않습니다. 파일 복사나 저장 과정에서도 수정 시각은 달라질 수 있습니다. 원본 두 개를 남겨 두고 내용의 차이와 수정한 이유를 비교한 뒤 새 통합본을 만드는 순서가 필요합니다.

합칠 기준과 범위를 정하세요 #

어느 파일을 기준으로 시작할지 정하고, 다른 파일에서 반영할 범위를 표시합니다. 문장 수정만 필요한지 표, 이미지와 첨부 자료까지 포함하는지 구분하세요. 두 파일 모두 보관한 상태에서 작업하고, 이름이 같은 파일을 한 폴더로 옮기며 덮어쓰지 않도록 주의합니다.

같은 구간을 다르게 바꾼 부분을 찾으세요 #

사용하는 편집기에 비교 기능이 있다면 사본으로 결과를 확인합니다. 기능이 없으면 제목이나 표 번호 같은 기준으로 구간을 나누어 대조할 수 있습니다. 표현만 달라진 경우와 수치·조건이 달라진 경우를 구분하세요. 의미가 충돌하는 수정을 최신 작성자의 의견이라는 이유만으로 선택하지 말고 근거 또는 작성자에게 확인합니다.

통합한 뒤 다시 읽어 보세요 #

개별 수정이 모두 맞더라도 합친 문서에서는 용어, 단위와 앞뒤 참조가 어긋날 수 있습니다. 목차, 표 합계, 그림 번호와 링크를 확인하고 중요한 변경은 원본과 다시 대조합니다. 확정한 통합본의 위치를 공유하고 이후 수정은 그 원본에서 이어가도록 안내하세요. 반복되는 혼선을 줄이려면 공동 문서 원본의 위치를 함께 관리하는 것이 도움이 됩니다.

조회수는 외부 서비스로 집계하며 새로고침·봇 요청이 포함될 수 있습니다.
