공유 표의 수식이 자꾸 지워진다면, 입력 칸과 결과 칸을 나누세요

표의 입력·계산·결과 영역을 구분하고 색뿐 아니라 안내와 보호 기능으로 편집 실수를 줄입니다.

도구생활 편집부 · 2026-11-15 · 2분 읽기NEW조회 0 (매시간 반영)

이 글의 목차

  1. 입력 칸의 의미와 단위를 적으세요
  2. 수식과 참고 값을 구분하세요
  3. 정상 값과 예외 값으로 확인하세요

여러 사람이 쓰는 표에서 수식이 값으로 바뀌거나 합계가 어긋난다면 사용자의 주의만 요구하기보다 표의 구조를 살펴볼 필요가 있습니다. 무엇을 입력해야 하고 무엇을 그대로 두어야 하는지 화면에서 분명해야 합니다. 입력, 계산, 결과를 나누고 처음 쓰는 사람도 작은 예제로 확인할 수 있게 만드세요.

입력 칸의 의미와 단위를 적으세요 #

열 제목에는 대상과 단위를 넣고, 빈칸이 미입력인지 해당 없음인지 구분합니다. 예시 값 하나를 별도 안내 영역에 보여 주면 문장만 읽는 것보다 이해하기 쉽습니다. 입력하지 말아야 할 곳을 색으로만 구분하지 말고 ‘자동 계산’처럼 텍스트도 함께 표시하세요.

수식과 참고 값을 구분하세요 #

계산에 사용하는 기준값과 사용자가 입력하는 값을 같은 열에 섞지 않습니다. 가능하면 계산 영역을 별도 시트나 구역으로 모으고 수정이 필요한 담당자를 정하세요. 편집기에서 지원하는 보호 기능은 실수 방지에 도움이 되지만, 그것만으로 민감한 정보의 접근 권한까지 안전하게 관리된다고 가정해서는 안 됩니다.

정상 값과 예외 값으로 확인하세요 #

사본에서 정상 입력뿐 아니라 빈칸, 0, 음수와 예상 범위를 벗어난 값을 시험합니다. 결과가 잘못됐을 때 사용자가 알아볼 표시가 있는지 확인하세요. 표를 늘렸을 때 새 행이 계산 범위에 포함되는지도 살펴야 합니다. 실제 공동 편집 권한으로 한 사람이 예제 입력을 해 보면 작성자에게는 익숙해서 보이지 않던 혼선을 찾을 수 있습니다.

조회수는 외부 서비스로 집계하며 새로고침·봇 요청이 포함될 수 있습니다.

  • 수정본 두 개를 합칠 때는 파일 날짜보다 변경 내용을 보세요
