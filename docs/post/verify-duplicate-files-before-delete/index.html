중복 파일은 이름보다 내용을 확인한 뒤 정리하세요

같은 이름의 파일도 내용은 다를 수 있습니다. 삭제 후보를 모으고 원본을 비교하는 순서를 정리합니다.

  1. 이름이 같은 것과 내용이 같은 것을 구분하세요
  2. 삭제 후보를 따로 모아두세요
  3. 한 묶음씩 사용 여부를 확인하세요

컴퓨터에 같은 문서가 여러 개 있으면 하나만 남기고 싶어집니다. 하지만 이름 끝의 숫자나 ‘복사본’이라는 표시만 보고 지우면 다른 사람이 수정한 내용까지 사라질 수 있습니다. 중복 정리의 첫 단계는 삭제가 아니라, 같은 자료인지 판단할 기준을 정하는 일입니다. 파일을 옮기거나 지우기 전에 현재 사용하는 원본 위치도 확인해 두세요.

이름이 같은 것과 내용이 같은 것을 구분하세요 #

예를 들어 ‘행사안내.pdf’가 다운로드 폴더와 공유 폴더에 각각 있어도 같은 파일이라고 단정할 수 없습니다. 이름, 파일 크기, 수정 날짜를 살펴본 뒤 실제로 열어 행사 날짜와 연락처 같은 주요 내용을 비교합니다. 크기와 날짜가 같다는 사실도 내용이 같다는 확실한 증거는 아닙니다. 편집 가능한 문서라면 주석이나 숨겨진 시트처럼 첫 화면에 보이지 않는 정보도 확인해야 합니다.

중복 확인 도구를 사용한다면 파일 이름만 비교하는지, 파일 내용의 해시값까지 비교하는지 살펴보세요. 해시값이 일치해 내용이 같더라도 저장 위치가 가진 역할은 다를 수 있습니다. 다른 문서가 특정 경로의 파일을 불러오거나, 팀이 그 위치를 원본으로 알고 있을 수 있기 때문입니다.

삭제 후보를 따로 모아두세요 #

바로 지우기보다 삭제 후보 목록을 만들고 보관할 파일의 경로를 함께 적습니다. 목록에는 파일 이름, 후보 위치, 남길 위치, 확인 이유 정도면 충분합니다. 회계 자료나 계약서처럼 보존 기준이 있는 파일은 중복 여부와 별개로 조직의 규칙을 따라야 합니다. 여러 사람이 쓰는 폴더라면 관리 담당자에게 원본을 먼저 확인합니다.

후보를 임시 폴더로 이동할 때도 주의가 필요합니다. 동기화된 폴더에서 이동하거나 삭제하면 다른 기기에도 반영될 수 있습니다. 중요한 파일은 복구 수단을 확인한 뒤 작은 범위부터 처리하고, 휴지통을 비우는 작업은 검증이 끝난 뒤로 미룹니다. 백업이 있다고 생각하는 것과 실제로 복원할 수 있는 것은 다릅니다.

한 묶음씩 사용 여부를 확인하세요 #

오늘은 프로젝트 하나에서 같은 내용으로 보이는 파일만 비교해 보세요. 남길 원본을 열 수 있는지 확인하고, 관련 문서의 연결이나 공유 경로도 점검합니다. 후보를 정리한 뒤에는 평소 작업 흐름으로 문서를 다시 열어보는 과정이 필요합니다. 문제가 없다면 다음 묶음으로 넘어가면 됩니다.

사진의 연속 촬영본이나 문서의 수정본은 비슷하다고 해서 중복이 아닙니다. 차이가 필요한 자료는 남기고, 왜 남겼는지 짧게 적어두세요. 파일 수를 최대한 줄이는 것보다 필요한 내용을 잃지 않고 원본을 찾는 상태가 정리의 기준입니다.
