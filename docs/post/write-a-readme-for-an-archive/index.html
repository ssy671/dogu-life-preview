압축 파일을 보내기 전, 안에 무엇이 있는지 안내 파일을 넣으세요

자료 묶음의 목적, 폴더 구성과 열어볼 순서를 적어 전달받는 사람이 원본을 찾기 쉽게 만듭니다.

  1. 포함한 자료와 제외한 자료를 적으세요
  2. 열어볼 순서와 필요한 조건을 설명하세요
  3. 실제 전달본을 다시 풀어 보세요

폴더를 압축해 보내면 전달은 간단해지지만 받는 사람은 어느 파일부터 열어야 할지 모를 수 있습니다. 파일 이름만으로 설명하기 어려운 맥락은 짧은 안내 파일에 남겨 보세요. 자료의 목적과 기준 버전, 폴더별 역할이 있으면 추가 질문을 줄이고 잘못된 파일을 수정하는 일을 예방할 수 있습니다.

포함한 자료와 제외한 자료를 적으세요 #

안내 파일 첫 부분에 전달 목적, 작성 날짜와 기준이 되는 결과물을 씁니다. 편집용 원본, 최종 출력물과 참고 자료의 위치를 구분하세요. 용량이나 권한 때문에 제외한 자료가 있다면 무엇이 빠졌고 어디에서 확인할 수 있는지 적습니다. 없는 파일이 들어 있는 것처럼 목록을 미리 채우지 않습니다.

열어볼 순서와 필요한 조건을 설명하세요 #

‘결과.pdf를 먼저 확인하고 수정이 필요하면 source 폴더를 사용’처럼 시작점을 한 문장으로 안내합니다. 특정 프로그램이나 별도 글꼴이 필요하면 이름과 확인한 환경을 남기세요. 외부 링크는 받는 사람의 권한으로 열리는지 확인해야 합니다. 암호가 있는 자료라면 암호 자체는 자료와 다른 적절한 전달 경로로 관리합니다.

실제 전달본을 다시 풀어 보세요 #

작업 폴더가 아니라 전달할 압축 파일을 별도 위치에 풀고 안내에 따라 대표 자료를 열어 봅니다. 임시 파일이나 불필요한 개인정보가 포함됐는지, 빠진 참조 자료는 없는지 확인하세요. 이후 수정본을 보낼 때는 바뀐 범위와 새 기준 버전을 함께 알려야 이전 전달본과 혼동하지 않습니다.

조회수는 외부 서비스로 집계하며 새로고침·봇 요청이 포함될 수 있습니다.
