물범 키캡 v2로 살펴보는 STL 크기와 메시 점검

물범 키캡 v2의 치수와 252,038개 삼각형을 확인했습니다. 닫힌 메시 검사와 실제 출력·MX 결합 검증의 차이, 단위와 크기 조절 때 주의할 점을 정리합니다.

파일이 열리는 것 다음에 볼 항목 #

Blender에서 만든 모델을 STL로 내보내면 일단 다음 단계로 넘어간 기분이 듭니다. 하지만 파일이 생겼다는 사실만으로 크기가 맞거나 출력 가능한 상태라고 결론 내리기는 어렵습니다. 이번에는 물범 키캡 v2의 검사 기록을 읽으며 무엇을 확인했고 무엇을 아직 모르는지 나눠 봤습니다. 초보자 입장에서는 검사 결과에 0이 많다는 것보다, 각 숫자가 어떤 질문에 답하는지 이해하는 편이 더 유용합니다.

대상은 물범과 베이스, 십자형 결합부를 포함한 v2 프로토타입입니다. 아래 수치는 저장된 검증 파일을 기준으로 했습니다. 프린터로 출력한 결과나 실제 스위치에 끼워 본 결과가 아니며, 특정 슬라이서나 Android 앱에서 정상적으로 가져온다는 확인도 포함하지 않습니다. 이 범위를 먼저 정해 두면 파일 검사에 기대할 수 있는 것도 선명해집니다.

설계 치수와 전체 치수부터 구분하기 #

v2 베이스의 기본 설계값은 18 × 18 × 8mm이고, 통합 형상의 전체 크기는 약 17.711 × 17.801 × 17.591mm입니다. 베이스의 높이 8mm를 전체 높이로 읽으면 물범이 차지하는 부분을 놓치게 됩니다. 반대로 전체 높이만 보고 베이스가 그만큼 두껍다고 생각해도 안 됩니다. 숫자 옆에 “베이스 설계값”과 “전체 외형”을 적어 두는 작은 습관이 혼동을 줄여 줍니다.

단위도 중요합니다. 이 프로젝트는 1 Blender 단위를 1mm로 사용했지만 STL 자체에는 단위 정보가 저장되지 않습니다. 가져오는 프로그램에서도 mm로 해석되는지 확인해야 합니다. 추후 슬라이서에 넣을 때는 자동으로 맞을 것이라 넘기지 말고 표시된 가로·세로·높이를 기록과 대조하는 순서가 필요합니다. 단위가 잘못 해석된 문제와 디자인을 실제로 크게 만들려는 변경은 먼저 구분해야 합니다. Blender 공식 STL 설명에서도 배율과 장면 단위 적용을 별도 항목으로 다룹니다. (Blender 공식 STL 설명)

삼각형 252038개와 오류 0의 의미 #

내보낸 STL의 검사 기록에는 삼각형 252,038개, 경계 모서리 0개, 정확히 두 면에 연결되지 않은 모서리 0개, 면 방향이 서로 일관되지 않은 모서리 0개가 남아 있습니다. 별도의 Blender 검증 기록에서는 비다양체 모서리 0개와 연결된 구성요소 1개를 확인했습니다. 서로 다른 검사에서 나온 값이므로 한 도구가 모든 항목을 확인한 것처럼 섞어 쓰지는 않습니다.

쉽게 말해, 이번 검사 범위에서는 열린 경계나 모서리 연결 문제를 찾지 못했고 형상은 하나로 연결되어 있었습니다. 삼각형 개수가 많다는 사실 자체가 품질 보증은 아닙니다. 또한 Blender 내부의 면 개수와 내보낸 STL의 삼각형 개수도 같은 숫자일 필요가 없습니다. STL은 삼각형으로 표면을 나타내므로 다른 종류의 면이 내보내기 과정에서 나뉠 수 있습니다. 비교할 때는 파일 형식과 검사 대상을 함께 적는 편이 정확합니다.

닫힌 메시 다음에는 얇은 부분과 출력 조건 #

위 결과로 확인한 것은 형상의 일부 기하학적 조건입니다. 벽이 충분히 두꺼운지, 작은 얼굴 요소가 남을지, 출력 방향에 따라 지지가 필요한 부분이 어디인지는 별도 문제입니다. Blender의 3D Print Toolbox 설명도 닫힌 형상 검사와 함께 두께나 오버행 등의 항목을 따로 다룹니다. 다만 이번 기록에 그 모든 검사를 실행했다는 뜻은 아닙니다. (Blender 3D Print Toolbox 설명)

앞으로 슬라이서에서는 단위와 전체 크기를 먼저 맞춰 보고, 층별 미리보기에서 비어야 할 공간과 남아야 할 벽이 어떻게 처리되는지 살펴볼 수 있습니다. 출력 방향, 서포트, 재료 수축도 조건에 맞춰 판단해야 합니다. 현재 파일에는 검증된 슬라이서 설정이나 서포트가 포함되어 있지 않습니다. “경계 모서리 0개”를 “어느 프린터에서나 바로 출력 가능”으로 바꾸어 읽지 않는 것이 중요합니다.

크기를 바꿀 때는 십자 홈까지 따라 움직입니다 #

물범을 조금 크게 보고 싶어서 모델 전체를 확대하면 아래쪽 십자 홈도 함께 커집니다. v2의 본체 소켓 설계값은 십자 전체 폭 4.15mm, 팔 폭 1.22mm, 유효 깊이 3.75mm입니다. 이 값은 실물 결합이 검증된 공차가 아니라 시험을 위한 설계값입니다. 전체 배율을 바꿔 외형을 조절한 뒤 원래 결합 조건이 그대로라고 생각해서는 안 됩니다.

수정 전에는 Blender 원본과 기존 STL을 보존하고 새 버전으로 저장하는 편이 좋습니다. 형상 크기와 소켓 치수는 목적을 나누어 다뤄야 합니다. 이번 파일에는 팔 폭이 1.17mm, 1.22mm, 1.27mm인 별도 결합부 테스트 조각도 있지만, 어느 값이 잘 맞는지는 아직 확인하지 않았습니다. 이후 같은 재료와 출력 조건으로 비교하고, 뻑뻑한 조각을 억지로 누르지 않는 과정이 필요합니다. 맞는 조각을 찾더라도 본체의 장착력과 키 이동, 주변 간섭은 다시 확인해야 합니다.

정리 파일 검사와 사용 검증 사이를 기록하기 #

이번에 확인한 것은 v2의 전체 크기와 메시 연결 상태입니다. 실제 출력과 MX 결합, 키 이동, 내구성은 남아 있는 확인 항목입니다. 검사 파일을 원본과 함께 보관하면 다음 수정 뒤에 어떤 수치가 달라졌는지도 비교할 수 있습니다. 성공했다는 한 문장보다 확인한 범위를 남기는 쪽이 다음 작업에 도움이 됩니다.

파일을 공유하거나 판매할 계획이라면 권리 확인도 따로 필요합니다. 참고 파일을 열어 볼 수 있다는 사실만으로 수정 파일의 배포나 디지털 재판매가 허용된다고 판단하지 않겠습니다. 외부 자료의 수정·배포·상업 이용 조건과 이미지 사용 범위를 확인하는 것을 공개 전 체크리스트에 넣습니다. 이는 이번 작업의 확인 원칙이며, 개별 라이선스에 대한 법률 판단은 아닙니다.

자료와 이어 읽기 #

v2의 README, create_seal_keycap.py, validation.json과 stl_checks.json을 기준으로 정리했습니다. 모델과 재생성 스크립트는 AI 어시스턴트가 만들었으며, 이 글은 저장된 파일 검사 기록을 설명합니다.

모양을 바꾼 이유와 화면 렌더의 의미는 물범 키캡 Blender v1·v2 수정 기록에서 확인할 수 있습니다.

조회수는 외부 서비스로 집계하며 새로고침·봇 요청이 포함될 수 있습니다.
