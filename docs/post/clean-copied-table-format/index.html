복사한 표가 어긋날 때는 모양보다 데이터부터 보세요

표를 다른 문서로 옮길 때 날짜, 숫자, 병합 셀과 서식이 바뀌는 문제를 확인하는 순서입니다.

도구생활 편집부 · 2026-10-22 · 3분 읽기NEW조회 0 (매시간 반영)

이 글의 목차

  1. 붙여넣기 전에 옮길 목적을 정하세요
  2. 숫자와 날짜가 바뀌지 않았는지 보세요
  3. 데이터 확인 뒤 서식을 정리하세요

웹 문서나 표 계산 도구에서 표를 복사하면 열 너비가 달라지거나 숫자가 다른 모양으로 보일 수 있습니다. 겉모양을 맞추느라 셀을 다시 합치기 전에 실제 값과 행의 관계가 유지되었는지 확인해야 합니다. 보기 좋은 표라도 값이 바뀌거나 제목과 데이터가 엇갈리면 자료로 쓰기 어렵습니다.

붙여넣기 전에 옮길 목적을 정하세요 #

계속 계산할 표인지, 보고서에 보여줄 표인지에 따라 옮기는 방식이 달라집니다. 계산과 수정이 필요하면 셀 구조를 살리고, 단순한 참고 화면이라면 이미지가 적절할 수도 있습니다. 다만 이미지는 내용을 검색하거나 복사하기 어렵고 접근성에도 한계가 있으므로 읽을 수 있는 설명과 원본을 함께 고려하세요.

원본의 행과 열 수, 제목 행, 합계 위치를 먼저 확인합니다. 병합된 셀이나 숨긴 행이 있으면 복사 결과가 예상과 다를 수 있습니다. 여러 줄로 된 한 셀의 내용이 다른 도구에서는 여러 행으로 나뉠 수도 있습니다. 전체 문서를 옮기기 전에 작은 구간으로 시험하면 문제를 파악하기 쉽습니다.

숫자와 날짜가 바뀌지 않았는지 보세요 #

붙여넣은 뒤에는 앞의 0이 필요한 코드, 긴 번호, 날짜와 백분율을 살펴봅니다. 도구가 값을 자동으로 해석하면 우편번호나 상품 코드가 숫자로 바뀔 수 있습니다. 표시 형식을 바꾸는 것과 원래 값을 복원하는 것은 다르므로, 문제가 생기면 원본을 기준으로 다시 가져와야 합니다.

예를 들어 ‘0012’는 코드라면 네 글자 모두 의미가 있지만 일반 숫자로 읽히면 앞의 0이 사라질 수 있습니다. 날짜도 월과 일이 바뀌어 해석될 수 있어 기준을 확인해야 합니다. 수식이 있는 셀은 계산식을 옮길지 결과 값만 옮길지 정합니다. 외부 문서 연결을 유지한다면 누가 접근할 수 있는지도 살펴보세요.

데이터 확인 뒤 서식을 정리하세요 #

값이 맞으면 불필요한 글꼴, 배경색, 테두리를 줄이고 제목과 단위를 일관되게 맞춥니다. 표의 의미를 전달하는 구분선과 강조는 남기되, 색상만으로 항목을 구분하지 않는 편이 좋습니다. 긴 표에서는 제목 행이 어디에 있는지 쉽게 알 수 있도록 구성하세요.

마지막으로 원본과 몇 개 행을 대조하고 전체 행 수와 합계를 확인합니다. 합계가 같아도 서로 다른 두 값이 바뀌었을 수 있으니 주요 항목을 직접 살펴보는 과정이 필요합니다. 원본은 검증이 끝날 때까지 보존하세요. 표를 옮기는 작업은 복사한 순간이 아니라 값과 의미가 유지되었음을 확인했을 때 끝납니다.

조회수는 외부 서비스로 집계하며 새로고침·봇 요청이 포함될 수 있습니다.
