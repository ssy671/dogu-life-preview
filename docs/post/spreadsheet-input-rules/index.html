스프레드시트 입력 규칙, 계산보다 먼저 맞춰야 할 것들

여러 사람이 쓰는 표에서 날짜, 상태, 빈칸의 의미를 먼저 정합니다. 입력 형식과 유효성 검사를 활용하고 잘못된 값이 들어오는 경로를 점검하는 방법입니다.

  3. 붙여넣기와 예외 입력을 점검하세요

각 열이 답할 질문을 정하세요 #

스프레드시트에서 같은 열에 서로 다른 의미의 값이 섞이면 정렬과 계산이 어려워집니다. 수식을 만들기 전에 각 열에 무엇을 적을지 정해 보세요. 요청일과 완료 예정일을 한 칸에 섞지 않고, 담당자 이름과 진행 상태도 구분합니다. 한 행이 신청 한 건인지 사람 한 명인지 명확하게 정하면 자료를 합칠 때 기준이 흔들리지 않습니다.

예를 들어 물품 요청을 관리한다면 수량, 단위, 필요 날짜를 각각 나누어 적을 수 있습니다. 수량 칸에 대략 다섯 개처럼 설명을 함께 쓰면 계산할 때 별도 처리가 필요합니다. 숫자와 설명을 분리하고 예외 사유는 다른 열에 남기세요. 처음부터 열을 지나치게 늘리기보다 실제로 조회하거나 비교할 항목을 기준으로 시작합니다.

날짜와 상태는 같은 방식으로 입력하세요 #

입력자가 같은 의미를 서로 다르게 적으면 필터 결과가 나뉩니다. 진행 중, 작업 중, 처리 중처럼 표현이 다양하다면 실제 업무 단계에 맞는 공통 값을 정해 보세요. 가능하다면 사용하는 도구의 선택 목록이나 입력 제한 기능을 활용할 수 있습니다. 다만 기능 이름과 적용 범위는 제품과 버전에 따라 다르므로 현재 환경에서 확인해야 합니다.

날짜는 화면에 보이는 모양과 실제 저장된 값이 다를 수 있습니다. 일부 행만 텍스트로 들어가면 날짜 정렬이나 계산이 예상과 달라질 수 있으므로 대표 값을 시험해 보세요. 빈칸도 미입력인지 해당 없음인지 의미를 정합니다. 아직 모르는 값에 임의의 숫자나 날짜를 넣으면 나중에 실제 값으로 오해할 수 있습니다.

붙여넣기와 예외 입력을 점검하세요 #

입력 규칙을 설정했더라도 외부 자료를 붙여넣거나 파일을 가져오는 과정에서 예상하지 못한 값이 생길 수 있습니다. 실제 사용 방식을 작은 예시로 시험해 보세요. 숫자 앞의 영이 중요한 코드라면 숫자로 바뀌며 정보가 사라지지 않는지 확인합니다. 원본을 보존한 상태에서 가져온 결과의 행 수와 주요 값을 대조하는 편이 안전합니다.

여러 사람이 편집한다면 규칙을 표와 가까운 위치에 짧게 남기고 변경 담당을 정합니다. 수식이 있는 영역을 보호할 수 있어도 권한 관리 전체를 대신하는 것은 아닙니다. 규칙을 바꿀 때에는 기존 값도 함께 검토하세요. 새 입력만 통일하고 과거 자료를 그대로 두면 같은 표 안에서 기준이 두 개가 될 수 있습니다.

조회수는 외부 서비스로 집계하며 새로고침·봇 요청이 포함될 수 있습니다.
