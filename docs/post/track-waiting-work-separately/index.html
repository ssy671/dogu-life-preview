답변을 기다리는 일은 내 할 일과 다른 목록에 두세요

대기 대상, 요청한 결과와 다시 확인할 날짜를 기록해 기다리는 업무가 계속 잊히는 일을 줄입니다.

도구생활 편집부 · 2026-11-14 · 2분 읽기NEW조회 0 (매시간 반영)

이 글의 목차

  1. 누구에게 무엇을 기다리는지 적으세요
  2. 응답 기한과 확인 날짜를 구분하세요
  3. 기다림이 끝나면 다음 상태로 옮기세요

오늘 할 일 목록에 같은 항목이 며칠째 남아 있다면 실제로는 다른 사람의 응답을 기다리는 일일 수 있습니다. 지금 실행할 수 없는 항목까지 모두 같은 목록에 넣으면 우선순위를 고르기 어려워집니다. 대기 중인 일은 따로 모으고, 내가 다시 확인할 행동만 일정에 남겨 보세요.

누구에게 무엇을 기다리는지 적으세요 #

‘검토 대기’ 대신 ‘담당자에게 문서 2쪽 수치의 확인 결과를 기다림’처럼 대상과 필요한 결과를 적습니다. 요청 날짜와 원문 위치를 함께 남기면 같은 설명을 다시 찾는 시간을 줄일 수 있습니다. 개인정보나 대화 전문을 복사하기보다 권한이 유지되는 원문 링크를 사용하세요.

응답 기한과 확인 날짜를 구분하세요 #

상대와 합의한 응답 기한이 없다면 임의로 마감이 확정된 것처럼 적지 않습니다. 대신 ‘수요일 오전에 진행 여부 확인’처럼 자신의 후속 행동을 정합니다. 결과가 늦어지면 어떤 작업이 영향을 받는지도 짧게 적어 둡니다. 영향이 없는 대기 항목까지 매일 재촉할 필요는 없습니다.

기다림이 끝나면 다음 상태로 옮기세요 #

응답이 왔다는 사실과 요청한 결과가 충족됐다는 사실은 다를 수 있습니다. 받은 내용을 확인해 바로 실행할 일, 추가 확인할 일, 종료할 일로 나눕니다. 대기 목록을 주기적으로 훑으면서 이미 필요 없어진 요청도 종료하세요. 진행 상황을 공유할 때는 완료·남은 일·막힌 이유를 구분하면 대기 상태를 설명하기 쉽습니다.

조회수는 외부 서비스로 집계하며 새로고침·봇 요청이 포함될 수 있습니다.

  • 결정이 자꾸 되풀이된다면, 결론 옆에 바꿀 조건을 적어 보세요
  • 반복되는 작은 실수, 체크리스트는 짧을수록 쓰기 쉽습니다
