CSV를 가져오기 전, 앞자리 0과 날짜부터 비교하세요

CSV 원본을 보존하고 구분자, 문자 인코딩과 열의 의미를 확인해 가져오기 과정의 변환 오류를 찾습니다.

도구생활 편집부 · 2026-11-13 · 2분 읽기NEW조회 1 (매시간 반영)

이 글의 목차

  1. 열을 나누는 기준부터 확인하세요
  2. 계산할 숫자와 식별자를 나누세요
  3. 행 수와 경계 사례를 대조하세요

CSV 파일은 여러 도구 사이에서 표를 옮길 때 편리하지만, 파일을 열었다고 모든 값이 원래 의미대로 읽힌 것은 아닙니다. 가져오는 프로그램이 숫자나 날짜를 자동으로 해석하면서 식별자의 앞자리 0이 사라지거나 날짜의 뜻이 달라질 수 있습니다. 먼저 사본으로 작업하고 대표 값을 원본과 비교하세요.

열을 나누는 기준부터 확인하세요 #

가져오기 미리보기가 있다면 한 행이 몇 개의 열로 나뉘는지 봅니다. 쉼표, 탭, 세미콜론 중 어떤 구분자를 썼는지에 따라 결과가 달라질 수 있습니다. 주소나 설명 안에 쉼표가 들어간 값을 단순한 찾기·바꾸기로 처리하지 마세요. 따옴표와 줄바꿈이 포함된 값은 CSV 형식을 이해하는 가져오기 기능으로 읽고 열 수를 확인하는 편이 안전합니다.

계산할 숫자와 식별자를 나누세요 #

사번, 우편번호, 주문 번호는 숫자로만 이루어져도 계산 대상이 아닐 수 있습니다. 이런 열은 원래 문자열을 유지할 수 있도록 가져오기 옵션을 확인합니다. 날짜도 ‘03/04’만으로는 월과 일의 순서가 불명확합니다. 작성한 쪽의 형식과 시간대가 필요한지 확인한 뒤 변환하세요. 프로그램마다 메뉴와 기본 처리 방식이 다르므로 작은 사본에서 먼저 시험합니다.

행 수와 경계 사례를 대조하세요 #

가져온 뒤에는 전체 행 수, 빈칸, 한글이 포함된 값, 앞자리 0이 있는 값과 긴 번호를 골라 비교합니다. 화면에 보이는 반올림이나 지수 표기만 보고 원래 값이 유지됐다고 판단하지 않습니다. 잘못 읽힌 파일을 원본 위에 저장하지 말고 가져오기 설정부터 고칩니다. 반복해서 전달하는 표라면 열 제목과 단위도 함께 합의해 두세요.

조회수는 외부 서비스로 집계하며 새로고침·봇 요청이 포함될 수 있습니다.

함께 읽으면 좋은 글

  • 공유 표의 수식이 자꾸 지워진다면, 입력 칸과 결과 칸을 나누세요
  • 수정본 두 개를 합칠 때는 파일 날짜보다 변경 내용을 보세요
  • 작업 기록 자동화, 자주 잊는 한 가지부터 시작하세요
