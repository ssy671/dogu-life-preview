스캔한 문서, 저장하기 전에 빠진 페이지와 글자를 확인하세요

종이 문서를 스캔한 뒤에는 페이지 수, 읽기 상태, 저장 위치를 차례로 확인해야 합니다. 원본을 성급하게 버리지 않고 필요한 정보를 다시 찾을 수 있게 보관하는 방법입니다.

원본과 페이지 수를 맞춰 보세요

스캔 파일이 만들어졌다는 표시만으로 문서 보관이 끝난 것은 아닙니다. 먼저 종이 원본의 장수와 파일의 페이지 수를 대조하세요. 양면 인쇄된 자료라면 뒷면이 누락되지 않았는지, 빈 페이지를 제외하는 과정에서 내용이 있는 면까지 빠지지 않았는지 확인합니다. 여러 문서를 한꺼번에 처리했다면 서로 다른 자료가 한 파일에 섞였는지도 살펴야 합니다.

예를 들어 신청서 세 장과 첨부 확인서 두 장을 함께 보관한다면, 어떤 순서로 읽어야 의미가 이어지는지 먼저 정합니다. 스캔한 결과를 첫 페이지부터 마지막까지 넘겨 보며 제목과 쪽번호를 원본과 비교하세요. 같은 장이 두 번 들어갔거나 방향이 뒤집힌 경우에는 제출 전에 바로잡습니다. 장수만 맞아도 내용 순서가 틀릴 수 있다는 점이 중요합니다.

중요한 글자는 확대해서 읽으세요

화면에 작은 미리보기가 보인다고 실제 내용까지 읽을 수 있다는 뜻은 아닙니다. 이름, 날짜, 금액, 표의 숫자처럼 잘못 읽으면 문제가 생기는 부분은 확대해서 확인하세요. 접힌 모서리나 제본 안쪽에 가려진 글자, 그림자 때문에 흐릿해진 문장이 없는지도 살핍니다. 한쪽 면만 잘 보이는 문서는 해당 부분을 다시 스캔하는 편이 낫습니다.

문자 인식 기능을 사용했다면 검색이 되는지 확인하되, 인식된 텍스트를 원문의 정확한 복사본으로 믿지는 마세요. 숫자와 영문, 비슷한 한글이 바뀔 수 있습니다. 서명이나 도장이 필요한 자료는 이미지에서 해당 부분이 보이는지도 따로 확인합니다. 민감한 문서를 처리할 때에는 사용한 서비스의 업로드 범위와 보관 방식을 확인해야 합니다.

파일 확인과 원본 처분은 나눠 판단하세요

읽기 상태가 충분하다면 문서를 목적에 맞는 위치에 저장하고 다시 열어 봅니다. 다른 기기나 전달받을 사람이 사용하는 환경에서도 파일이 열리는지 확인하면 좋습니다. 검색용 제목에는 문서 종류와 관련 업무를 드러내되, 파일명에 주민등록번호 같은 민감한 정보를 그대로 적지 않습니다. 필요한 접근 권한도 함께 점검하세요.

스캔이 끝났다고 종이 원본을 곧바로 폐기해서는 안 됩니다. 계약, 증빙, 제출 서류는 원본 보관 요구가 있을 수 있으므로 발급 기관이나 관련 규정을 먼저 확인합니다. 종이를 보관해야 한다면 디지털 파일에 원본 위치를 메모해 두세요. 파일의 완전성을 확인하는 일과 종이를 버려도 되는지 판단하는 일은 각각 근거가 필요합니다.

조회수는 외부 서비스로 집계하며 새로고침·봇 요청이 포함될 수 있습니다.

함께 읽으면 좋은 글

  • 중복 파일은 이름보다 내용을 확인한 뒤 정리하세요
  • 외장 저장장치에 무엇이 있는지, 연결하기 전에 알 수 있게 기록하세요
  • 사진을 행사별로 모을 때, 날짜보다 먼저 정할 보관 기준
