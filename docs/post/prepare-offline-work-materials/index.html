인터넷이 끊겨도 할 수 있는 작업을 한 묶음 준비하세요

자료 저장과 실제 오프라인 열기를 구분하고, 재연결 후 원본과 합치는 방법까지 준비합니다.

도구생활 편집부 · 2026-11-14 · 2분 읽기NEW조회 0 (매시간 반영)

이 글의 목차

  1. 연결이 필요 없는 결과물을 고르세요
  2. 저장 표시보다 실제 열기를 확인하세요
  3. 다시 연결할 때 비교할 지점을 남기세요

이동 중이거나 연결이 불안정한 장소에서 일할 때는 모든 자료를 내려받는 것보다 오프라인으로 끝낼 수 있는 작업 하나를 정하는 편이 실용적입니다. 폴더에 파일 이름이 보이는 것과 그 내용이 기기에 저장되어 있는 것은 다를 수 있습니다. 출발 전에 실제로 열리는지 확인하고 수정본을 어디에 남길지도 정하세요.

연결이 필요 없는 결과물을 고르세요 #

문서의 개요 작성, 이미 받은 자료의 검토처럼 필요한 입력이 갖춰진 작업을 선택합니다. 실시간 협업이나 최신 수치 조회가 필요한 일은 따로 표시합니다. 필요한 자료만 허용된 기기에 저장하고, 업무 자료를 개인 저장소로 옮겨 편의를 해결하지는 마세요.

저장 표시보다 실제 열기를 확인하세요 #

중요한 전송이 진행 중이지 않을 때 네트워크 연결을 잠시 끊고 준비한 자료를 열어 봅니다. 문서 본문뿐 아니라 첨부 그림, 참조 파일과 필요한 프로그램의 사용 가능 여부도 확인하세요. 클라우드 서비스의 오프라인 지원과 로그인 조건은 서비스마다 다릅니다. 읽기만 가능한지 수정도 가능한지는 별도로 시험해야 합니다.

다시 연결할 때 비교할 지점을 남기세요 #

오프라인 사본에는 작업 날짜와 수정한 구간을 기록합니다. 연결이 돌아왔을 때 공동 원본이 달라졌다면 곧바로 덮어쓰지 말고 변경 부분을 비교하세요. 자동으로 병합될 것이라고 가정하지 않는 편이 좋습니다. 작업이 끝난 사본은 정한 보관 기준에 따라 정리하고, 다음 이동 때 다시 필요한 최소 자료만 준비합니다.

조회수는 외부 서비스로 집계하며 새로고침·봇 요청이 포함될 수 있습니다.

함께 읽으면 좋은 글

  • 압축 파일을 보내기 전, 안에 무엇이 있는지 안내 파일을 넣으세요
  • 파일 이름을 한꺼번에 바꾸기 전, 바뀔 이름 목록부터 확인하세요
  • 백업이 있다는 말보다, 파일 하나를 복구해 본 기록이 중요합니다
