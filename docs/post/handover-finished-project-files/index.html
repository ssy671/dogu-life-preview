프로젝트가 끝난 뒤, 자료를 넘겨받을 사람을 위한 정리

완료 파일과 작업 중 파일을 구분하고, 다음 담당자가 필요한 자료를 찾고 열 수 있는지 확인하세요.

도구생활 편집부 · 2026-10-28 · 2분 읽기NEW조회 0 (매시간 반영)

이 글의 목차

  1. 결과물과 작업 흔적을 구분하세요
  2. 처음 열어 볼 안내 문서를 두세요
  3. 전달받은 계정으로 열어 보세요

프로젝트 폴더를 통째로 전달했는데도 다음 담당자가 어떤 문서를 써야 할지 묻는다면, 자료가 없는 것이 아니라 설명이 부족한 상태일 수 있습니다. 완료 자료를 전달하는 일에는 최종 결과물뿐 아니라 판단 근거와 남은 일도 포함됩니다. 지금까지 일한 과정을 모두 복원하게 하기보다, 처음 보는 사람이 다음 행동을 시작할 수 있도록 입구를 만드는 것이 좋습니다.

결과물과 작업 흔적을 구분하세요 #

먼저 실제로 사용할 완료 파일이 무엇인지 표시합니다. 기획안, 납품용 이미지, 운영 매뉴얼처럼 결과물별로 기준이 되는 파일을 정하고 초안이나 중간 수정본과 구분하세요. ‘최종’이라는 단어만 반복하기보다 승인 일자와 사용 목적을 함께 적으면 판단에 도움이 됩니다. 진행 중인 계약이나 검토가 남아 있다면 완료로 묶지 말고 상태를 설명합니다. 다만 모든 초안을 삭제할 필요는 없습니다. 결정 과정이나 변경 근거를 설명하는 자료는 별도 기록으로 남길 수 있고, 보존 의무가 있는 문서는 관련 기준을 따릅니다.

처음 열어 볼 안내 문서를 두세요 #

폴더의 첫 화면에서 찾기 쉬운 위치에 자료 안내를 둡니다. 안내에는 프로젝트 목적, 최종 결과물 위치, 담당 업무, 남은 확인 사항을 간결하게 연결하세요. 예를 들어 ‘다음 행사에서 수정할 안내문은 이 파일이며, 날짜와 연락처를 먼저 확인한다’고 쓰면 단순 파일 목록보다 쓸모가 있습니다. 외부 자료나 사용한 이미지에 이용 조건이 있다면 그 조건도 확인할 수 있게 남깁니다. 설명을 길게 쓰기보다 자주 물을 만한 질문에 답하는 방식이 좋습니다. 파일을 다른 위치로 옮길 계획이 있다면 안내 문서의 링크도 함께 바뀌는지 점검하세요.

전달받은 계정으로 열어 보세요 #

본인에게 열리는 링크가 다음 담당자에게도 열리는 것은 아닙니다. 가능한 범위에서 전달받을 사람이 실제 사용할 계정으로 접근과 편집 범위를 확인하게 하세요. 개인 계정에 묶인 원본, 외부 공유가 제한된 문서, 특정 프로그램에서만 열리는 파일은 전달 전에 조건을 설명합니다. 암호나 개인 인증 수단을 자료 안내에 적어 넘기는 방식은 피하고 조직이 정한 이관 절차를 사용합니다. 전달이 끝났다면 누가 관리할지와 이후 문의 창구를 정합니다. 담당자와 접근 권한이 정리되어야 파일 전달이 실제 업무 인수로 이어집니다.

조회수는 외부 서비스로 집계하며 새로고침·봇 요청이 포함될 수 있습니다.

함께 읽으면 좋은 글

  • 오래된 자료가 생각나지 않을 때, 검색어를 바꾸는 순서
  • 가입한 계정 목록을 만들 때, 암호 없이도 관리할 수 있습니다
